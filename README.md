# version-control-simulation-Safaa

During this project, I learned how to use Git to manage branches, track changes, and resolve merge conflicts.

I created two branches from `main`, made changes to the same file, and committed my changes. When I merged the branches, I learned how conflicts happen when two branches modify the same line differently. I resolved the conflict by reviewing both changes, choosing the version I wanted, and committing the resolution.

I also practiced creating a pull request on GitHub. I learned that pull requests allow other developers to review code, suggest improvements, and catch mistakes before merging changes.

Overall, this project helped me understand Git branching, merging, conflict resolution, and how developers collaborate using GitHub.
